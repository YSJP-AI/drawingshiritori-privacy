本プライバシーポリシー（以下「本ポリシー」）は、Kakuni（以下「運営者」）が提供するiOSアプリ「しりとり画伯」（以下「本アプリ」）における、利用者情報の取扱いについて説明するものです。

1. 本アプリについて

本アプリは、絵しりとりを楽しむゲームアプリです。オフラインでのプレイに加え、Game Center を利用したオンライン対戦（招待および近くの人との対戦）、広告の表示、広告削除の買い切り（アプリ内課金）と購入の復元などを提供します。

運営者は、本アプリのために独自の会員登録サーバや、作品を自動収集する運営者サーバを用意していません。絵や設定などのゲームデータは、原則として利用者の端末内に保存され、運営者が独自サーバへ自動的に収集するものではありません。

2. 取得・保存する情報

2.1 端末内に保存される情報（運営者は常時取得しません）

次の情報は、本アプリの機能のために利用者の端末内に保存されます。運営者がこれらのデータをサーバ経由で自動的に収集・閲覧する仕組みはありません。

  • ゲーム中に描いた絵のデータ（端末のメモリ上および、中断保存時の端末内ファイル）
  • 画廊（お気に入り）に保存した作品、画伯名、作品名（端末内の Application Support）
  • 画伯名の履歴（端末内の UserDefaults）
  • BGMのオン／オフなどのアプリ設定（端末内の UserDefaults）
  • 中断したゲームの再開用データ（該当する場合、端末内の Application Support）

これらのデータは、利用者がアプリ内で削除した場合、または本アプリをアンインストールした場合などに、端末から削除され得ます。

2.2 利用者が操作したときに扱う情報

  • 写真ライブラリへの保存
    利用者が、本アプリで作成した画像を写真アプリへ保存することを選んだ場合に限り、iOSの機能（写真ライブラリへの追加のみの権限）を使って画像を追加保存します。利用者の既存の写真を読み取ったり、写真ライブラリ全体を閲覧したりするものではありません。
  • 共有
    利用者が共有を選んだ場合、iOSの共有シートを通じて、利用者が選んだアプリやサービスへ画像等が渡されます。共有先での取扱いは、各サービスの方針に従います。
  • お問い合わせ
    利用者が運営者へメールで連絡した場合、そのメールアドレス、本文、および返信に必要な情報が、問い合わせ対応のために扱われます。これはアプリ内の自動送信ではなく、利用者がメールアプリ等を通じて送った内容です。

2.3 Apple（App Store / StoreKit / Game Center）が扱う情報

本アプリは Apple のサービスを利用します。次の情報は、主に Apple 側で処理されます。運営者がクレジットカード番号などの決済情報を直接受け取ることはありません。

  • アプリ内課金（StoreKit）
    「広告を削除」の購入および「購入を復元」は App Store / StoreKit を通じて行われます。購入・決済の詳細は Apple が管理します。運営者（本アプリ）が端末上で確認・利用するのは、StoreKit のトランザクション情報に基づく「広告削除が有効かどうか」という購入状態に限ります。運営者の独自サーバへ購入情報を送信する仕組みはありません。
  • Game Center / オンライン対戦
    オンライン対戦（招待）および近くの人との対戦では、Apple の Game Center（GameKit）を利用します。その過程で、Apple アカウントに紐づく識別子、表示名、マッチングや通信に必要な情報が Apple 側で処理される場合があります。
    対戦中、参加者同士の端末間で、ゲーム進行に必要なデータ（アプリ内で設定した画伯名などの参加者情報、進行状態、および描いた絵の画像データを含む）が GameKit の通信により送受信されます。これは運営者の独自サーバへ絵をアップロードするものではありません。
    本アプリが端末上で参照するのは、Game Center 認証状態や対戦の進行に必要な識別子・表示用の画伯名など、対戦機能の提供に必要な範囲に限ります。運営者がこれらを独自サーバへ保存する仕組みはありません。
    近くの人との対戦では、端末のローカルネットワーク機能（Bonjour 等）を利用します。許可の状態は iOS の設定で確認・変更できます。

詳細は Apple の説明をご確認ください。
Apple のプライバシーポリシー

2.4 広告（Google Mobile Ads / AdMob）が扱う情報

本アプリは、広告表示のために Google の広告サービス（Google Mobile Ads SDK / AdMob）を利用します。広告の配信、表示、効果測定、不正防止などのために、Google 等の広告関連サービス側で、次のような情報が取り扱われる場合があります。

  • 端末やアプリに関する情報
  • IPアドレス（およその位置の推定に用いられる場合があります）
  • 広告識別子（IDFA 等）その他の端末識別子
  • 広告の表示や操作に関する情報
  • 診断情報、パフォーマンスに関する情報、クラッシュ等の技術情報

これらの取扱いは、主に Google 等のサービス側の仕組みによるものです。運営者は、利用者の絵や画伯名を広告目的で収集・販売することはありません。「広告を削除」を購入した場合、本アプリ側の実装により、当該広告の表示を停止します。

本アプリにおけるトラッキングの取扱いについては、App Store のプライバシー情報および iOS の App Tracking Transparency の仕組みに従います。端末の設定から、アプリにトラッキングを許可しないよう求めることもできます。

詳細は Google の説明をご確認ください。

運営者は、法令に基づく場合等を除き、運営者が保有する個人情報を第三者へ提供しません。ただし、本アプリが利用する Apple、Google 等の第三者サービスについては、各サービスの提供に必要な範囲で、各事業者が情報を取得・処理する場合があります。

  • 法令に基づく場合

  • 公衆衛生の向上または児童の健全な育成の推進のために特に必要で、本人の同意を得ることが困難な場合

  • あらかじめ本人の同意がある場合

5. 保存期間

  • 端末内データ
    利用者が削除するまで、またはアプリアンインストール等により端末から消去されるまで、端末内に保存されます。運営者のサーバには保存されません。
  • お問い合わせ内容
    利用者がメールで送った内容は、対応に必要な期間、運営者が保存し、不要になった後は削除します。法令により保管が必要な場合は、その期間に従います。
  • 課金関連情報
    購入・決済の詳細は Apple が管理します。本アプリでは、広告削除が有効かどうかなど、機能提供に必要な購入状態を端末上で StoreKit 経由で確認します。運営者のサーバには保存しません。
  • 広告関連情報
    Google 等の広告サービス側のポリシーに従います。運営者が独自に広告関連の個人情報をサーバへ蓄積する仕組みはありません。
  • Game Center 関連情報
    Apple のポリシーおよびサービス仕様に従います。運営者のサーバには保存しません。

運営者は、取り扱う情報の漏えい、滅失、毀損の防止のため、合理的な安全管理措置を講じます。なお、インターネットやモバイル端末の性質上、絶対的な安全を保証することはできません。
